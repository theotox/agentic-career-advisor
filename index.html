Ένα πειραματικό σύστημα τεχνητής νοημοσύνης διπλού κόμβου (Dual-LLM), που παρακάμπτει τα συμβατικά frameworks (όπως το LangGraph) χρησιμοποιώντας δυναμικό Prompt Injection και ψυχομετρικό State Tracking σε πραγματικό χρόνο.

Αρχιτεκτονική Dual-Node

Πώς δύο διαφορετικοί Agents συγχρονίζονται σε λιγότερο από 1 δευτερόλεπτο για να αξιολογήσουν και να καθοδηγήσουν τον χρήστη.

Χρήστης

Στέλνει απαντήσεις φυσικής γλώσσας (Chat).

Agent 1: Ο Αξιολογητής

Αόρατος. Αναλύει το ιστορικό και εξάγει JSON με το ψυχομετρικό προφίλ (~3.5s).

Prompt Injection

Agent 2: Ο Σύμβουλος

Λαμβάνει τις μυστικές οδηγίες και απαντά στον χρήστη ρεαλιστικά (~0.7s).

Το "Reality Check" Metric

Αντί για ένα απλό chatbot που συμφωνεί με τα πάντα, το σύστημα παρακολουθεί δυναμικά το "Χάσμα" μεταξύ ονείρου και προσπάθειας.

  • Delusion Level (Δείκτης Ψευδαίσθησης) Όσο υψηλότερος ο δείκτης (π.χ. θέλει να γίνει ιατρός αλλά μισεί το διάβασμα), τόσο πιο "αυστηρός" γίνεται ο Agent 2.
  • Willingness to Sweat (Προθυμία) Μετράει την ανθεκτικότητα και την εργασιακή ηθική βάσει του ιστορικού και των χόμπι του χρήστη.
evaluator_output.json 
{
  "psychometric_profile": {
    "teamwork_vs_independence": 0.8,
    "resilience_to_failure": 0.6
  },
  "reality_check_metrics": {
    "stated_dream_job": "Professional Fisherman",
    "delusion_level": 0.7,
    "willingness_to_sweat": 0.3
  },
  "agent_directives": {
    "recommended_llm1_stance": "highlight the contrast between idealized fishing and actual labor"
  }
}
